# 배포 시나리오

이 디렉터리는 Storix의 유일하거나 표준적인 배포 방법을 정의하지 않는다.

각 시나리오는 특정 물리 자원, 네트워크, 보안, 운영 제약에서 사용할 수 있는
독립적인 배포 예시다. 운영자는 자신의 환경에 맞는 시나리오를 선택하거나 필요한
부분만 조합하고, 적용 조건과 알려진 제약을 직접 검토해야 한다.

## 시나리오 목록

| 시나리오 | 개발 환경 | 운영 환경 | 핵심 제약 |
| --- | --- | --- | --- |
| [기존 Nginx의 내부 mTLS listener](co-located-nginx-mtls/README.md) | 단일 호스트, SQLite 또는 PostgreSQL | 2개 애플리케이션 노드, 공유 PostgreSQL·NAS | 회사 L7 LB를 우회하는 WAS → Nginx mTLS |

## 작성 규칙

- 디렉터리 이름은 순번이 아닌 안정적인 영문 slug를 사용한다.
- 설명과 실제 설정 파일을 같은 시나리오 디렉터리에서 관리한다.
- 개발·운영 토폴로지와 둘 사이의 설정 차이를 함께 기록한다.
- 비밀키, 인증서, 실제 자격증명은 커밋하지 않는다.
- 특정 시나리오의 선택을 Storix 전체의 기본값이나 제품 계약으로 확대하지 않는다.
